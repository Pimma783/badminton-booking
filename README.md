# Badminton Club — แบบฝึกหัด OOP

โปรแกรมจัดการจองสนามแบดมินตันด้วย **Java 17 + JavaFX 21.0.6 + FXML** สำหรับเปิดใน IntelliJ IDEA และออกแบบหน้าจอด้วย SceneBuilder ใช้ Maven Wrapper 3.9.9 จึงไม่จำเป็นต้องติดตั้ง Maven แยก

## เริ่มใช้งานในเครื่องนี้

1. ดับเบิลคลิก **`run.cmd`** เพื่อเปิดโปรแกรม สคริปต์จะค้นหา JDK ใน `.jdks` ของผู้ใช้ให้ ครั้งแรกต้องใช้อินเทอร์เน็ตเพื่อดาวน์โหลด Maven และ dependencies
2. เข้าสู่ระบบด้วยบัญชีสาธิตด้านล่าง
3. ไปแท็บ **สมาชิก** กรอกชื่อและเบอร์โทร แล้วกดสมัครสมาชิก
4. ไปแท็บ **จองสนาม** เลือกสมาชิก วัน สนาม เวลา จำนวนชั่วโมง และวิธีจ่าย แนบสลิป PNG/JPG/PDF แล้วกดบันทึก
5. ผู้ดูแลระบบควรตั้ง **วันหยุดนักขัตฤกษ์** ตามปฏิทินสถานที่ก่อนรับจอง

ไฟล์ ZIP ที่ส่งให้มี JAR และไลบรารีที่ build แล้วใน `target/` สามารถใช้ **`run-offline.cmd`** เพื่อเปิดได้ทันทีโดยไม่ต้องดาวน์โหลด dependencies เพิ่ม (ยังต้องมี JDK 17 ขึ้นไป) หากแก้โค้ดหรือ FXML ให้ใช้ `run.cmd` เพื่อ build ตามไฟล์ล่าสุด

| บทบาท | ชื่อผู้ใช้ | รหัสผ่าน |
|---|---|---|
| พนักงานแคชเชียร์ | `cashier` | `cashier123` |
| ผู้ดูแลระบบ | `admin` | `admin123` |

บัญชีนี้เป็นบัญชีสาธิตสำหรับงานเรียน ผู้ดูแลมีสิทธิ์ทำรายการทั่วไปได้ด้วย นอกเหนือจากดูประวัติ รายได้ และตั้งวันหยุด

## เปิดและรันใน IntelliJ IDEA

1. เลือก **File > Open** แล้วเปิดโฟลเดอร์โปรเจกต์นี้ หรือไฟล์ `pom.xml` และเลือกเปิดเป็นโปรเจกต์ Maven
2. รอ Maven sync ให้เสร็จ หากมีคำถาม Trust Project ให้ตรวจโค้ดแล้วเลือกตามความเหมาะสม
3. เลือก **File > Project Structure > Project SDK** เป็น JDK 17 ในเครื่อง (`ms-17`)
4. เลือก Run Configuration **Badminton Club** แล้วกด ▶ หรือเปิดหน้าต่าง Maven > Plugins > javafx > **javafx:run**
5. หากไม่มี configuration ให้สร้าง Maven configuration โดยใส่ Run/Command line เป็น `javafx:run` และ Working directory เป็นโฟลเดอร์นี้

คลาสเริ่มต้นคือ `com.badminton.Main` แต่แนะนำรันผ่าน Maven เพื่อจัดการ JavaFX dependencies ให้ครบ

## แก้หน้าจอด้วย SceneBuilder

ดับเบิลคลิก **`open-scenebuilder.cmd`** เพื่อเปิดหน้าหลักด้วย SceneBuilder ที่ติดตั้งไว้ในเครื่อง หรือเปิดไฟล์เหล่านี้ด้วย File > Open ของ SceneBuilder:

- `src/main/resources/com/badminton/view/login.fxml` — หน้าเข้าสู่ระบบ
- `src/main/resources/com/badminton/view/main.fxml` — หน้าหลักและแท็บทั้งหมด
- `src/main/resources/com/badminton/view/theme.css` — สี ฟอนต์ และรูปแบบหน้าจอ

ใน IntelliJ ตั้ง **Settings > Languages & Frameworks > JavaFX > Path to SceneBuilder** เป็น `C:\Users\phatt\AppData\Local\SceneBuilder\SceneBuilder.exe` แล้วคลิกขวา FXML > Open in SceneBuilder ได้เช่นกัน

**อย่าเปลี่ยน `fx:id`, `fx:controller` หรือชื่อ `onAction` โดยไม่แก้ Controller ให้ตรงกัน** หน้าจอใช้ controls มาตรฐาน ไม่ต้องเพิ่ม custom library ให้ SceneBuilder การเปิด FXML ใน SceneBuilder เป็นการแก้ layout; ให้รันโปรแกรมจริงเพื่อทดลองข้อมูลและปุ่ม

## กติกาที่เลือกใช้ในส่วนที่โจทย์ไม่ได้ระบุละเอียด

- จองเป็นชั่วโมงเต็ม เริ่มตรงชั่วโมง ไม่รองรับเศษชั่วโมง และไม่รับจองย้อนหลังหรือเวลาเริ่มที่ผ่านไปแล้ว
- นับชั่วโมงสะสมเมื่อ **บันทึกการจองสำเร็จ** รวมการใช้แพ็กเกจ และให้สิทธิ์ที่ชั่วโมง 20, 40, 60, ... ไม่มีการยกเลิกจองในเวอร์ชันนี้
- หากใช้แพ็กเกจแล้วชนชั่วโมงลดราคา ชั่วโมงนั้นจ่ายเงิน **54 บาทโดยไม่ตัดเครดิตแพ็กเกจ** ชั่วโมงอื่นตัดเครดิตตามจริง การซื้อแพ็กเกจเองยังไม่นับเป็นชั่วโมงที่จอง
- วิธีใช้แพ็กเกจต้องมีเครดิตครบสำหรับชั่วโมงที่ต้องตัด ไม่ผสมเงินกับแพ็กเกจโดยอัตโนมัติ ยกเว้นชั่วโมงส่วนลดข้างต้น
- ต้องแนบหลักฐานทุกครั้งที่จอง แม้รายการนั้นใช้แพ็กเกจทั้งหมด โดยอาจใช้สลิปซื้อแพ็กเกจเดิมเป็นหลักฐานได้ การแนบไฟล์ไม่ใช่การตรวจยืนยันยอดกับธนาคาร
- รับ PNG, JPG, PDF ไม่เกิน 10 MB ตรวจชนิดจาก file signature และคัดลอกเก็บในแฟ้มข้อมูล
- วันหยุดนักขัตฤกษ์เป็นรายการที่ผู้ดูแลกำหนด ไม่ได้ดึงปฏิทินออนไลน์ เสาร์/อาทิตย์ตรวจอัตโนมัติ
- เช่าอุปกรณ์ 50 บาทต่อคู่ **ต่อรายการเช่าภายในวันเดียว** หากเช่าใหม่เป็นอีกครั้งมีค่าใช้จ่ายเพิ่ม ไม่ได้เก็บสต็อกอุปกรณ์เช่าหรือจัดการคืนในโจทย์นี้
- ธุรกรรมขาย/เช่าอุปกรณ์ผูกกับสมาชิกเพื่อค้นประวัติได้สะดวก ชำระทันทีเมื่อกด “รับเงินและบันทึก”
- รายงานนับรายได้ตาม **วันรับเงิน** ในเขตเวลา Asia/Bangkok เงิน 2,600 บาทนับตอนซื้อแพ็กเกจ ไม่คิดรายได้ซ้ำเมื่อนำชั่วโมงมาใช้ วันที่ในโปรแกรมแสดง **ค.ศ.** รูปแบบ `dd/MM/yyyy`

## โครงสร้างและหลัก OOP สำหรับอธิบายงาน

```text
src/main/java/com/badminton/
  Main.java, BadmintonApp.java     จุดเริ่มต้น, โหลด FXML, ตรวจโปรแกรมเปิดซ้ำ
  model/                          สมาชิก การจอง สินค้า การเช่า การรับเงิน และผู้ใช้
  service/                        กติกาเวลา ราคา สิทธิ์ และธุรกรรม
  repository/                     อ่าน/เขียนข้อมูลผ่าน interface
  controller/                     รับ event จาก FXML และเรียก service
src/main/resources/com/badminton/view/
  login.fxml, main.fxml, theme.css หน้าจอที่เปิดใน SceneBuilder ได้
src/test/java/                    ทดสอบธุรกิจและโหลดหน้าจอจริง
docs/OOP.md                       อธิบาย OOP และแผนภาพคลาส
```

**Encapsulation:** ข้อมูลธุรกิจเป็น immutable record และ service เป็นผู้ปรับยอดอย่างมีเงื่อนไข ไม่มีให้ UI แก้ยอดแพ็กเกจหรือยอดเงินโดยตรง

**Inheritance/Abstraction:** `Cashier` และ `Administrator` สืบทอด `StaffUser` ซึ่งเป็น abstract class

**Polymorphism:** เรียก `StaffUser.canViewReports()` ผ่านชนิดแม่ แต่แต่ละบทบาทคืนสิทธิ์ต่างกัน ส่วน `ClubService` รับ `PricingPolicy` และ `ClubRepository` เป็น interface จึงเปลี่ยนวิธีคิดราคาหรือฐานข้อมูลได้โดยไม่แก้ UI

**Separation of concerns:** FXML แสดงผล, Controller จัดการเหตุการณ์, Service ตรวจเงื่อนไข, Repository บันทึกข้อมูล

## การบันทึกและสำรองข้อมูล

- `data/club-data.bin` เก็บข้อมูลสมาชิก การจอง แพ็กเกจ สต็อก การรับเงิน การเช่า และวันหยุด
- `data/receipts/` เก็บสำเนาสลิป การย้ายหรือลบสลิปต้นฉบับไม่กระทบสำเนาที่เก็บไว้
- บันทึกหลังทำรายการสำเร็จ เขียนไฟล์ชั่วคราวแล้วแทนไฟล์เดิม และเปลี่ยนข้อมูลในหน่วยความจำหลังบันทึกสำเร็จเท่านั้น
- เปิดพร้อมกันได้หนึ่ง instance ต่อแฟ้มข้อมูล ป้องกันหลายหน้าต่างเขียนทับกัน
- **ปิดโปรแกรมก่อนสำรองข้อมูล แล้วคัดลอกทั้งโฟลเดอร์ `data`** อย่าคัดลอกเฉพาะไฟล์ `.bin` หากต้องการเก็บสลิปด้วย
- เปลี่ยนตำแหน่งข้อมูลด้วย JVM property `-Dbadminton.data.dir=...` เมื่อรัน Java โดยตรง
- โปรแกรมเริ่มด้วยข้อมูลสมาชิก/การจองว่าง มีเฉพาะรายการสินค้าพื้นฐาน ไม่มีข้อมูลตัวอย่างปะปนในข้อมูลใช้งาน

## ทดสอบและแพ็กโปรแกรม

ดับเบิลคลิก `test.cmd` หรือรัน PowerShell:

```powershell
.\scripts\project.ps1 -Action test
.\scripts\project.ps1 -Action package
```

คำสั่ง `package` สร้าง `target/badminton-booking-1.0.0.jar` และ `target/lib` สามารถรันด้วย JDK 17:

```powershell
java -jar target/badminton-booking-1.0.0.jar
```

หากย้าย JAR ให้ย้ายโฟลเดอร์ `lib` ไปข้าง JAR ด้วย หรือใช้ซอร์สพร้อม Maven Wrapper แทน ไม่ใช่ native `.exe` ที่รวม JDK

การทดสอบครอบคลุมเวลาเปิด/ปิด สนามซ้อน สนามครบ 12 สนาม ชื่อ/เบอร์สมาชิก สลิป แพ็กเกจ ชั่วโมงส่วนลด สต็อก สิทธิ์ผู้ใช้ รายได้ การอ่านข้อมูลกลับ การบันทึกล้มเหลว และ FXML จริง ภาพหน้าจอจากการทดสอบอยู่ใน `target/ui-preview/` การทดสอบ FXML ใช้ Windows desktop session ที่เปิดกราฟิกได้

เอกสารอ้างอิงการใช้งาน JavaFX: [OpenJFX + Maven](https://openjfx.io/openjfx-docs/) และ [FXMLLoader](https://openjfx.io/javadoc/21/javafx.fxml/javafx/fxml/FXMLLoader.html)
